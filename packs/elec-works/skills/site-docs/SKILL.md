# 현장 공무 서류 자동화

**회사 양식을 그대로 두고 빈칸만 채워** 서류 초안을 만든다. 양식이 바뀌면 `양식/` 폴더의 파일만 바꾸면 된다.

## 먼저 확인할 것 (없으면 멈춘다)

1. 만들려는 서류의 **회사 양식**이 작업 폴더의 `양식/` 에 있는지 본다.
2. 없으면 알리고 멈춘다: "이 서류의 회사 양식이 `양식/` 폴더에 없습니다. 양식 파일을 넣어 주세요. 양식 없이 임의로 만들지 않습니다."
3. 같은 서류의 **작성 규칙**(항목 순서, 필수 기재 사항, 파일 이름 규칙)이 `rules/<서류이름>.md` 에 있는지 본다. 없으면 사용자에게 한 번 물어 적어 두자고 제안한다(예: "착공계에 꼭 들어가는 항목을 알려 주세요").

## 서류별 흐름

| 서류 | 입력 | 출력 |
|---|---|---|
| 자재승인원(검수 요청서) | 자재 목록, 카탈로그·시험성적서 PDF | 양식에 채운 승인원 초안 |
| 착공계·시공계획서 | 현장 정보, 공정표 | 양식에 채운 초안 |
| 주간·월간 공정회의록 | 회의 메모, 지난 회의록 | 같은 서식의 회의록 |
| 준공서류 | 뒤섞인 시험성적서·도면 | 공종별 분류 **미리보기 표**(옛 이름 → 새 이름), 확인 후 적용 |

## 도구

- PDF·MS 문서 읽기: `python -m markitdown <파일>` 또는 설치된 문서 스킬
- 한글(HWP·HWPX) 양식: `kordoc` 스킬(양식 채우기)
- 모든 사실(규격·수량·날짜)은 **원본에서 옮긴 것만** 쓴다. 원본에 없으면 빈칸으로 두고 "확인 필요"로 표시한다.

## 답변 규칙

- 결과 끝에 항상 붙인다: **"초안입니다. 제출 전에 담당자가 내용을 확인하세요."**
- 값을 채우지 못한 칸은 목록으로 알려 준다.
- 제출·메일 전송·포털 업로드는 하지 않는다. 사용자에게 넘긴다.
- 준공서류 이름 변경은 미리보기 표를 보이고 확인을 받은 뒤에만 하며, 이력을 `.cowork/rename-log.csv` 에 남긴다.

## 파일 규칙

- `받은자료/` 는 읽기만 한다. 결과는 `작업중/` 에 새 파일로 저장하고 원본 양식은 바꾸지 않는다.
