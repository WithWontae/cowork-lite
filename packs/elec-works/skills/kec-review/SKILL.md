# KEC 검토

설계도면·부하표·시공 내용이 KEC 기준에 맞는지 **참고용으로** 점검한다. 최종 판단은 사용자(담당 기술자)가 한다.

## 먼저 확인할 것 (없으면 멈춘다)

1. `data/kec-clauses.csv`, `data/cable-ampacity.csv`, `data/voltage-drop-formulas.json` 에 **행이 채워져 있는지** 본다.
2. 비어 있으면 이렇게 알리고 멈춘다: "기준 데이터가 아직 없습니다. KEC 원문(최신 개정본)에서 확인한 값을 `data/` 에 넣어 주세요. 제가 임의로 수치를 채우지 않습니다."
3. 행마다 `출처`와 `기준일`이 있는지 본다. 없으면 그 행은 쓰지 않고 사용자에게 알린다.

## 하는 일

| 요청 | 방법 |
|---|---|
| 전선 굵기·차단기 용량 검토 | 부하전류와 설치 방법을 사용자에게 확인 → `cable-ampacity.csv` 의 허용전류와 비교 → 표로 보여 줌 |
| 전압강하 | `scripts/voltage_drop.py` 로 계산(아래 사용법). 계산식은 `voltage-drop-formulas.json` 을 따른다 |
| 접지·이격거리 | `kec-clauses.csv` 에서 해당 조항을 찾아 **조항 번호와 함께** 보여 줌 |

### 전압강하 계산

```
python scripts/voltage_drop.py --system 3p3w --length-m 120 --current-a 45 --area-mm2 25 --voltage 380
```

결과(전압강하 V, 비율 %)를 표로 보여 주고 허용 한도와 비교한다. 한도 값은 `kec-clauses.csv` 의 조항에서 가져오며, 없으면 비교하지 않고 "한도 기준 데이터가 없습니다"라고 한다.

## 답변 규칙

- 모든 판단에 **근거 조항 번호와 기준일**을 붙인다. 근거가 없으면 "근거를 찾지 못했습니다"라고 쓴다.
- 결과 끝에 항상 붙인다: **"참고용 초안입니다. 담당 기술자가 KEC 원문을 확인해 최종 판단하세요."**
- 부적합 가능성이 있는 항목은 먼저, 쉬운 말로 적는다(예: "이 전선은 부하전류에 비해 가늘 수 있습니다").
- 모르면 추측하지 않는다.

## 파일 규칙

- 입력 도면·부하표는 읽기만 한다. 결과표는 `작업중/` 에 새 파일로 저장한다.
