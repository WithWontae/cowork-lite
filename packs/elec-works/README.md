# 전기 공무 확장팩 (`elec-works`) — 뼈대

**상태: 뼈대 + 설치 연결.** 스킬의 구조와 규칙, 계산 스크립트, 기준 데이터 **빈 양식**이 있다. 설치기가 이 폴더의 스킬 3종을 `~/.claude/skills/` 에 복사한다(`lib/skills.sh`). 실제 기준 데이터는 스킬 폴더가 아니라 **작업 폴더의 `.cowork/data/elec-works/`** 에 두고(동기화되고, 설치 때 덮어쓰지 않는다), 사용자가 Claude 에 "온보딩"이라고 보내면 인터뷰로 채운다(설계 §6.6). 이 폴더의 `data/` 는 빈 양식(헤더)일 뿐이다.

## 구성

| 스킬 | 하는 일 | 스크립트 | 기준 데이터(사용자가 공식 원문으로 채움) |
|---|---|---|---|
| `kec-review` | KEC 검토: 차단기 용량·전선 굵기, 접지·이격거리, 전압강하 | `voltage_drop.py` | `kec-clauses.csv`, `cable-ampacity.csv`, `voltage-drop-formulas.json` |
| `std-estimate` | 표준품셈·적산 보조: 일위대가 검증, 설계변경 단가 근거 | `unit_price.py` | `labor-norms.csv`, `unit-wages.csv`, `surcharge-rules.csv` |
| `site-docs` | 공무 서류: 착공계·시공계획서·자재승인원·준공서류·회의록 | 없음(양식 채우기) | 회사 양식(`양식/` 폴더) |

## 원칙

1. **수치를 지어내지 않는다.** KEC 조항, 허용전류, 품셈 수량·단가·할증은 사용자가 공식 원문(최신 개정본)에서 확인해 `data/` 에 넣는다. 비어 있으면 스킬은 "기준 데이터가 없습니다"라고 알리고 멈춘다.
2. **출처와 기준일을 남긴다.** 데이터 파일의 모든 행에 `출처`(문서명·조항·판)와 `기준일`이 있어야 쓴다.
3. **결과는 사용자 검토 필수.** 모든 결과에 "참고용 초안 — 담당자 검토 필요"를 붙인다.
4. **받은자료는 수정하지 않는다.** 결과는 `작업중/` 또는 `결과물/` 에 새 파일로 저장한다.
5. **외부로 나가는 것은 확인한다.** 제출·전송은 스킬이 하지 않고 사용자에게 넘긴다(설계 §6.3).
